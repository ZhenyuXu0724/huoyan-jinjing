11 月 11 日和 18 日的数据按拍摄组划为训练 170 张、验证 42 张。11 月 14 日的 98 张全部用于本轮测试，包含 21 张纯正常件图和 77 张混合图。测试已采用大螺母与细螺钉的修正版标注。这批照片在早期实验中已使用过。

### OpenCV 补漏对照

后续用同一批已保存的预测做诊断：保留全部 YOLO 框，只将与所有 YOLO 框均无交集的额外轮廓补为干扰件。正常件检出恢复至 963/980，新外形干扰件检出为 62/232，77 张混合图仍只有 2 张六类全对。纯 YOLO 有 166 个新外形干扰件被误认成正常件，补漏后这一数字相同。该项属于测试后的错误分析。

### 文件与运行

- [完整实验报告](实验报告.md)、[310 张图片的划分与原图哈希](split.json)、[训练配置](protocol.json)、[逐轮训练记录](results.csv)、[验证集选阈值记录](selection.json)。
- [下载模型与评估记录](https://github.com/ZhenyuXu0724/huoyan-jinjing/releases/download/member05-nov14-date-holdout-v1/member05-nov14-date-holdout.zip)。包内含训练后权重、A/B 推理代码和配置、310 份 YOLO 标签、逐图预测与验证网格结果。文件校验值见 [SHA256SUMS](SHA256SUMS)。
- 运行推理时解压模型包，按包内《运行说明》选择 A 或 B。使用 CUDA 的 Python 环境，具体软件版本见包内 environment.txt。
- 复现训练时准备三批原图、官方 yolov8n.pt 与解压后的模型包，在本目录运行下方命令。脚本按原图 SHA256 匹配文件，使用本次固定划分与修正后的标签。将四个示例路径替换为实际位置。

```powershell
python train.py --images "三批原图所在目录" --initial "yolov8n.pt" --package "模型包解压目录" --output "本次新建目录"
```
