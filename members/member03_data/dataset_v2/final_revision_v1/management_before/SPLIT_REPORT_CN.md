# Dataset v2 划分设计、数据审查与完整性验证报告

## 二、各批次切分依据与异常构成明细

1. **`11/11_parts_v1`（160 张原图）**：
   - 包含 `标准光正视`、`暗光正视图`、`标准光侧视图`、`暗光侧视图` 四种拍摄条件各 40 张。
   - `暗光正视图`、`标准光侧视图`、`暗光侧视图` 各按文件名顺序取前 `32` 张入 `Train PASS`、后 `8` 张入 `Val PASS`（共 `96 Train / 24 Val`）。
   - `标准光正视` 含唯一历史缺件图 `IMG_7209.png`（少 1 个 `M5x10`），取前 `31` 张入 `Train PASS`、后 `9` 张中的 `8` 张正常图入 `Val PASS`、`IMG_7209.png` 入 `Val FAIL`。旧公开 `test` 分区曾被历史实验/审计读取，不再作为独立测试集。
2. **`11/14_PASS`（21 张原图）**：
   - 按拍摄时间顺序取前 `16` 张（`160608..160917`）入 `Train PASS`，末尾 `5` 张（`160929..161025`）入 `Val PASS`；前段 3 对高框重叠连拍全部保留在 `Train` 内。
3. **`11/14_FAIL`（77 张原图，含上游 `16d9239` 标注修订）**：
   - 按相邻拍摄间隔 `≥30s` 划分为 `B01..B11` 共 11 个时间块，将完整时间块 `B01`（1 张 `nc=1`）、`B03`（1 张 `nc=6`）、`B08`（10 张 `nc=6`）、`B11`（6 张 `nc=7`）共 `18` 张划入 `Val FAIL`，其余 7 个完整块共 `59` 张（`5` 张 `nc=1`、`40` 张 `nc=6`、`14` 张 `nc=7`）划入 `Train FAIL`。
   - 组内全部 53 对旋转不变框重叠 `>0.35` 的高相似对（最高 `0.9238`）均完整保留在同一分区内，跨分区配对 `>0.35` 数量为 `0`（跨区最高仅 `0.1355`）。
4. **`11/18_FAIL`（52 张原图）**：
   - 按间隔 `≥25s` 划分为 `B01..B05` 共 5 个时间块。含 9 张“3 目录外 + 缺 `M4x25`”复合异常的 `B01`（12 张）完整保留在 `Train FAIL`，将独立块 `B03`（12 张，全为“仅含 3 个目录外件”）划入 `Val FAIL`，其余块归入 `Train FAIL`（合计 `40 Train / 12 Val`）。
5. **`11/20` 原图（70 张）与 `11.20_泛化增强`（210 张）**：
   - 70 张原图按间隔 `≥60s` 划分为 `B01..B11` 共 11 个时间块：`B01..B06` 与 `B08`（`2 PASS + 46 FAIL = 48`）入 `Train`；`B07`（`6 FAIL`）入 `Val`；`B09..B11`（`16 FAIL`）入 `Test 候选`。

### 3.1 空标注图像 `MVIMG_20261120_172557.jpg` 人工目视核查
- **核查结果**：已直接调阅原图目视检查，确认画面为**真实空白检测台面**（左侧白纸带同一细小笔迹及右侧柔和阴影，台面内确实没有任何机械零件，不存在漏标物体）。
- **处理方式**：保持原始空框标注（`"shapes": []`）不作任何改动，按 `[2,2,2,2,2]` 规则正常归入 `test/FAIL/original/`（异常类别记为 `empty_scene`），其 3 张派生增强图同步归入 `test/FAIL/augmented/`。

### 3.2 上游修订标注与哈希清单说明
- 采用当前分支最新上游修订文件，包含 commit `16d9239` 对 `11.14训练补强＋干扰验证/验证集_不要训练/IMG_20261114_162432.json` 的螺母/螺丝标签交换修正，以及对 `11.20` 垫圈标签的修正。

### 3.3 跨分区旋转不变布局相似性核查（已修复空框除零并全量复跑）

> **方法学边界声明**：框重叠度低仅表示这一坐标及匹配方法得到较低分数，不能确认零件布局已重新打散，**不能单独作为物理场景/背景会话完全独立的充分证明**。

## 四、已知局限与待团队确认事项（诚实披露）

1. **`test/` 仅为 `PROVISIONAL_HOLDOUT`（暂定留出集），不能直接宣称满足课程正式盲测门槛**：
   - `test/` 仅含 **29 张真实原图**（`13 PASS` + `16 FAIL`），其余 **48 张均为派生增强图**；真实正常样本（13 张）尚低于课程/计划建议的 `≥15 PASS` 及 `≥30` 独立物理场景起步目标。
   - `11/20` 与 `11/23` 数据此前已上传至共享分支，其他成员是否已读取或用于训练需全组交叉核实。
2. **同会话背景关联**：
   - 目视抽检 `11/23` 跨时间块边界原图（`MVIMG_20261123_182155.jpg` 与 `MVIMG_20261123_182326.jpg`）确认零件位置已完全重摆，但左侧垫纸边缘存在同一细小笔迹且左上角露出同一桌面边缘，说明 `11/23` 的 `6 Train` 与 `13 Test 候选` 共享同一拍摄背景会话；`Test 候选` 中 `PASS`（11/23）与 `FAIL`（11/20）仍来自不同拍摄日期。
3. **新批次正常图的验证覆盖缺口**：
   - `Val` 中来自 `11/20` 的 6 张原图全部为 `FAIL`，尚无 `11/20` 或 `11/23` 批次的正常图进入 `Val`，验证集对新拍摄会话正常图的误拒监测能力有限。
4. **上游用途变更与待复核标记**：
   - `11.14/验证集_不要训练` 中有 `59` 张被纳入 `Dataset v2` 的 `Train`，且该批次在成员 6 历史 `DEV v1/v2` 中曾用作验证集；正式用于团队模型前须经组长与成员 3 确认用途变更，且新旧数据集上的验证指标不可直接横向等同比较。
   - 源 JSON 中原有的 `auto_label_review` 待人工复核标记及 `IMG_7209.png` 缺件真值按原样保留并在 `dataset_manifest.csv` 的 `quality_notes` 列显式记录，未做任何擅自涂改。
