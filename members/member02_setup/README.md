# 成员 2 · 装置、标定与采集组织

## 职责

实物规格核对、相机支架、白底补光、尺度标定、误差试验和采集排班。

**交付物：** 实物目录；装置照片；采集 SOP；标定脚本与版本；尺寸误差和容差草案；采集条件记录。

**协作：** 向成员 5/6 提供有效尺度及适用范围；与成员 3 联合制定采集任务卡；向组长提供教师确认材料。

**验收：** M4×10 与 M5×10 的差异可观察；重复标定误差可报告；相机改变后能重新建立尺度。

**边界：** 负责统一设备与采集组织，不独自承担全部拍摄、标注；不凭单个像素阈值保证规格正确。

## 本模块运行说明

### 当前状态

已完成初步拍摄装置搭建和图像采集，四组数据共 160 张照片。初步数据已由成员 3 上传并提交 PR，自动化标签脚本由成员 3 负责。

当前模块主要交付为拍摄条件记录、采集规范、装置说明及后续标定支持，尚未完成独立标定程序和测量误差实验。

### 设备与拍摄环境

- 相机设备：iPhone 7。
- 拍摄模式：手机默认拍摄模式。
- 固定方式：手机支架固定。
- 拍摄背景：白纸。
- 补光方式：自然环境光及手机闪光灯。
- 相机到检测平面的距离：尚未测量。
- 相机具体俯拍角度：尚未测量。

### 初步数据采集条件

| 组别 | 拍摄角度 | 闪光灯 | 数量 |
|---|---|---|---:|
| Group 1 | 正上方俯拍 | 关闭 | 40 |
| Group 2 | 正上方俯拍 | 开启 | 40 |
| Group 3 | 略微降低拍摄视角 | 开启 | 40 |
| Group 4 | 略微降低拍摄视角 | 关闭 | 40 |

每张照片均包含十个配齐的零件。每次拍摄前重新打乱零件位置，尽量保证零件在画面中均匀分布，避免过度密集或过度分散。

### 初步采集 SOP

1. 将白纸铺设在检测平面上。
2. 将手机固定在支架上，保持拍摄装置稳定。
3. 将十个零件全部放置在拍摄区域内。
4. 每次拍摄前重新打乱零件位置，尽量保证分布均匀。
5. 按照对应组别设置闪光灯和拍摄角度。
6. 拍摄并保存图像，按照组别整理数据。
7. 检查图像是否清晰、零件是否完整出现在画面中，以及是否存在明显遮挡。

### 尺度标定与误差说明

当前采集尚未加入标尺或已知尺寸参照物，手机支架高度和具体拍摄角度也未测量，因此暂不提供像素与实际毫米之间的换算关系。

YOLO 检测框和 ResNet 分类结果本身不等于真实尺寸标定结果。若后续任务需要实际尺寸测量，应增加已知尺寸参照物，建立像素尺度关系，并记录其适用范围。

当前四组数据主要用于初步研究光照和拍摄视角变化对视觉识别的影响，不作为高精度尺寸测量数据。
