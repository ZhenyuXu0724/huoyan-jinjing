# 单类模型实现

使用说明集中在 [模块入口](../README.md)，请按 [复现步骤](../docs/WORKFLOW.md) 执行。

| 文件 | 责任 |
|---|---|
| `prepare.py` | 按固定上游文件索引下载并校验，分别生成开发与测试清单 |
| `settings.py` | 从模块位置加载实验组，固定随机种子 |
| `train.py` | 仅用 PASS 拟合标准化器和自编码器，验证选阈值、组织消融 |
| `scoring.py` | 重建均方误差与验证阈值选择，无训练或测试文件访问 |
| `report.py` | 汇总真实运行记录，复制选定权重，生成交接预测和报告 |
| `audit.py` | 冻结后核对完整交付包的源文件、原始框、数量与分区重复 |

训练不做验证早停：固定预算结束后保存最后一轮，再计算验证误差和阈值。它与早期“双类监督 MLP、按验证损失保存”的计划不同，是按用户要求改成仅 PASS 训练后的实现。

继续已有实验前会检查数据身份、训练代码、轮数、参数和模型校验值。不匹配时应创建新的输出与权重目录，不能覆盖旧版本冒充同一实验。
