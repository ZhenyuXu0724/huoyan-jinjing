# 实验组与对照顺序

组定义在 [geometry.json](geometry.json) 和 [photometric.json](photometric.json)，其余固定参数由 [训练实现](../../one_class/train.py) 统一设置。每次运行的完整配置保存到 `outputs/member04_hog/experiments/组名/seed42/config.json`，不能只凭组名猜参数。

| 组 | 相对 A0 唯一改动 | 用途 |
|---|---|---|
| A0 | 不增强 | 基础对照 |
| A1 | 原图、左右镜像 | 检验左右方向变化 |
| A2 | 原图、上下镜像 | 检验上下方向变化 |
| A3 | 0°、90°、180°、270° | 检验直角朝向 |
| A4 | 原图、左右、上下、180° | 检验双轴镜像组合 |
| A5 | 旋转加镜像的 8 种唯一视图 | 检验完整方向组合 |
| B1 | 训练 Gamma 从 0.8、1.0、1.2 采样 | 检验光照扰动 |
| B2 | 训练和推理均 CLAHE，clip_limit=0.01 | 检验局部对比度 |

几何 JSON 每项为 `[逆时针旋转90°次数, 是否再左右镜像]`。例如 `[2,true]` 等价于上下镜像。左右后上下翻转等价于 180°，不重复计数。所有变换在补成正方形后进行，不裁切原有零件。

每轮每张训练图片只均匀采样一个视图；各组原图数量、200 轮预算、3 个种子（42/43/44）相同。增强不会生成新的独立场景，也不作用于验证或测试。

## 组合及选择

先独立比较 A0–A5、B1、B2。只保留验证平均 FAIL F1 严格高于 A0 的单项；几何只取其中最佳组。至少两项合格才运行 C0，并生成 `C_without_geometry`、`C_without_gamma` 或 `C_without_clahe` 逐项移除对照。实际生成项以本轮 summary 和 config 为准。

最终按 3 种子平均验证 FAIL F1 选择方案，并列优先启用项少、视图少的方案；集成固定使用该组 seed42，不按测试成绩或最佳种子挑选。每组阈值仅从验证集选，测试不再更改。

## 后续实验规则

更高分辨率、细 HOG 单元等属于后续新版本实验，须先写对照方案。每次只改变一个因素，继续保持训练、验证与测试隔离，不能根据本轮测试结果回调当前模型。
