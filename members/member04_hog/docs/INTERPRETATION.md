# 方法、指标与结果怎么读

## 基础流程

1. **方向校正与预处理**：根据 EXIF 恢复照片方向，转灰度，等比例缩放并补白到 256×256，避免把零件拉长。
2. **HOG（方向梯度直方图）**：统计局部边缘方向。使用 9 个方向、16×16 像素单元、2×2 单元块和 L2-Hys 归一化。特征仍含位置和朝向信息。
3. **标准化**：只从训练 PASS 学习每维均值与尺度，验证和测试沿用，不能重新拟合。
4. **MLP 自编码器**：网络把 HOG 压缩再还原，隐藏层为 64–16–64。输入与训练目标都是同一 HOG；Adam 学习率 0.001，L2 正则 0.0001，固定训练 200 轮。
5. **判定**：还原特征与输入特征的均方误差超过验证阈值时判 FAIL。它不是概率，也不能定位错误零件。

只用 PASS 可以学习“正常外观”，但异常不一定难以重建；正常图片的背景或摆放变化也可能产生高误差。因此必须看真实验证和错误样本，不能只看训练损失下降。

## 本项目常用名词

| 名词 | 在这里具体指什么 |
|---|---|
| 特征 | 图片转成的一串数字；当前 HOG 为 8100 维 |
| 自编码器 | 学习把输入还原成自身的网络，训练目标不是 PASS/FAIL 标签 |
| ReLU | 隐藏层的激活函数，将负值变成零，让网络能学习非线性关系 |
| Adam | 根据训练误差调整网络参数的方法；验证图片不参与这些更新 |
| L2 正则 | 给过大的权重增加代价，缓解只记住训练样本的倾向 |
| epoch / 轮 | 每张训练图片各提供一个视图的一次完整遍历 |
| seed / 种子 | 固定初始化、顺序和增强采样，便于复现；不能替代新采集数据 |
| Gamma | 用像素值的幂变换模拟亮暗变化，1.0 表示不变 |
| CLAHE | 限制对比度的局部直方图均衡，用于改善局部明暗对比 |
| 消融 | 固定其他条件，只加入或移除一个因素，观察指标变化 |
| 冻结 | 把模型、阈值和规则固定并保存校验值，之后才看测试结果 |

## 改动为什么要做

镜像与直角旋转针对方向敏感；Gamma 针对亮度变化；CLAHE 针对局部对比度。先各自对照 A0，再组合改善项，最后逐项移除。一次改很多项就无法知道改善由谁带来。各组更新预算相同，避免“增强组训练更多次”的混淆。

验证阈值候选取误差边界与相邻误差中点，依次优先 FAIL F1、平衡准确率、更少误拒、更大阈值。组别按 3 个种子的平均验证 F1 选，报告样本标准差。阈值和方案都用了验证标签，验证分数是开发结果，不是独立测试估计。

## 混淆矩阵与覆盖率

本项目以 **FAIL 为正类**。

| 真值 / 预测 | FAIL | PASS |
|---|---|---|
| FAIL | TP：拦截正确 | FN：错误放行，漏放 |
| PASS | FP：错误拒绝，误拒 | TN：放行正确 |

- Precision = TP/(TP+FP)：判 FAIL 的图有多少真是 FAIL。
- Recall = TP/(TP+FN)：真实 FAIL 有多少被拦截。
- F1 = 2TP/(2TP+FP+FN)：精确率与召回率的综合。
- 平衡准确率 =（FAIL Recall + PASS 正确率）/2，避免多数类掩盖少数类问题。
- 覆盖率 = 有效 PASS/FAIL 判定数/全部请求数。异常状态单列，不当作正确，也不从总请求数消失。

例如 TP=3、FP=1、FN=1、TN=3：Precision=Recall=F1=0.75；若另有 2 张输入失败，则覆盖率为 8/10=0.8，混淆矩阵仍只针对 8 张有效判定。分母为零时代码返回 0 以保持数值可计算，但报告须说明该类没有支持，不能解释为有统计意义的性能。

## 共同评价文件

`compare.py` 真值 CSV 列为 `image_id,count_1,count_2,count_3,count_4,count_5,non_catalogue_count,annotation_status`。状态 `VERIFIED` 才参与判定，`UNJUDGEABLE` 单列排除。数量请求 JSON 与 [示例](../examples/expected_counts.json) 一致；模型输入只接收请求，不能接收真值计数。

各模型导出 `images.csv` 至少包含 `image_id,model_id,status,predicted_label`。文件名覆盖必须一致、不可重复；不同模型在同一固定规则下比较。成员 4 不会为其他模型补造框或对象数。

## 结果与能力边界

先读本轮 `REPORT.md` 中的数据支持数，再看单项对照、组合移除、所选组相对 A0 的变化，最后看冻结后测试。F1 升高也可能伴随误拒增加，必须同时报告误拒和漏放。

现有验证 FAIL 主要为目录外干扰，不足以证明所有少件、错规格或新背景能力。场景与人工审核尚未完成，公开 test 也不能代替后续独立新采样。CPU 离线时间不包含摄像头与显示，成员 7 仍需测现场端到端 Median/P95。
