## 数据与训练规则

数据固定至上游 127eeded2d9e7ceebb802b26f6ab9f3ccac9ef26。训练使用 133 张 PASS，其中旧 train 112 张、新补强 21 张。验证使用 24 张 PASS 和 77 张 FAIL。验证目录中的图片只参与阈值和方案选择。

采用 256×256 等比例补白灰度图、9 方向 HOG、16×16 单元、2×2 单元块及 L2-Hys。MLP 自编码器为 64–16–64 隐藏层，Adam 学习率 0.001，L2 系数 0.0001。标准化器和权重只学习训练 PASS。每组使用种子 42、43、44，固定 200 轮，保存最后一轮。验证阈值先最大化 FAIL F1，再比较平衡准确率、误拒数和阈值大小。

本分区只有 1 张 FAIL 和 23 张 PASS。样本少的类别不能给出稳定性能结论；若某类为零，其 Recall/F1 的数值约定不代表测得能力。完整错误 ID 保留在 assessment/test 的逐图记录与 metrics.json。

按交付标注，IMG_7209.png 为 FAIL，类别 0–5 的计数为 [0, 2, 1, 2, 2, 2]。这是标注派生标签，仍需成员 3 完成人工复核。

所选模型仍有测试漏放，不能据验证高 F1 宣称具备可靠现场检测能力。验证异常主要是目录外干扰，而测试失败类型及正常图像条件不同，这一差异提示泛化不足；尚不能仅凭本轮结果确定原因。保留当前失败记录，不切回测试表现更好的对照、不调阈值。

## 局限与工程解释

旧数据按文件名分段，实物场景独立性未核实。同一摆放的连拍或光照变体可能跨分区，验证和测试成绩可能偏乐观。已有 test 已公开，测试结果应称为提供分区评测。它不能代替后续按独立实物场景采集的新测试。

新增验证 FAIL 主要由目标数量正确但混入目录外件构成。损伤、真实少件、多出合规件、相似错规格等能力，应按各自的真实支持数解释。来源许可、垫圈规格和预标注最终人工审核仍沿用成员 3 的待确认状态。

自编码器学习正常图像的重建，HOG 保留位置与方向信息。重建误差可能同时受背景、摆放和拍摄条件影响。高误差不能直接定位或说明是哪颗零件出错。
