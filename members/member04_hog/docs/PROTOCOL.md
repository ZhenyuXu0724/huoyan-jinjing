# 方法与实验协议

本文件对应机器可读唯一任务单 `configs/final_v4/protocol.json`（75 次正式训练：66 次主实验 + 9 次有限改进）。协议在开发数据审计通过后冻结；代码、清单或来源变化会拒绝复用已有训练目录。

## 版本与统一名称

前缀 `Baseline1_HOGMLP_v4_FinalDataset_`：

| 后缀 | 方法 |
|---|---|
| `PASSOnly_Autoencoder` | HOG + 仅 PASS 训练的 MLP 自编码器 |
| `Supervised_MLP` | HOG + 监督二分类 MLP |
| `Supervised_Capacity_L2_EpochSelection` | 监督模型的容量、L2 与验证选轮次 |
| `Rebuild` | 本轮综合交付包 |

组名与种子放在子目录，不虚构额外版本。

## 预处理与特征

- 256×256；EXIF 方向校正；等比例 LANCZOS 缩放；居中白色补边；灰度。
- HOG：9 方向、16×16 单元、2×2 单元块、L2-Hys，8100 维。
- CLAHE 组在训练、验证和推理一致应用，`clip_limit=0.01`；Gamma 仅用于训练视图；验证和 test 不随机增强。
- 每轮每张原图只取一个随机视图；不通过展开增强图片增加训练预算。

## 共同训练设置

ReLU、Adam、学习率 0.001、L2=0.0001、batch size=32、200 轮、单线程、关闭内部早停和洗牌。每轮用一个 `partial_fit` 遍历一次训练原图；保存 200 轮训练损失。主实验固定使用第 200 轮，不在 66 次内额外挑轮次。

- AE：`MLPRegressor(hidden_layer_sizes=(64,16,64))`，只用 166 张 PASS 原图；标准化器只拟合这 166 张原图的对应预处理特征；增强视图同时作为重建目标；得分为标准化 HOG 重建均方误差。
- 监督：`MLPClassifier(hidden_layer_sizes=(64,16))`，用 249 张原图；标准化器只拟合这 249 张原图；PASS=0、FAIL=1；样本权重 249/(2×本类数量)=PASS 0.75、FAIL 1.5；得分为未校准 FAIL 输出，不与 AE 重建误差比较数值。

## 11 组配置

| 组 | 设置 | 训练视图 |
|---|---|---:|
| A0 | 原图 | 1 |
| A1 | 原图＋左右镜像 | 2 |
| A2 | 原图＋上下镜像 | 2 |
| A3 | 0/90/180/270 度旋转 | 4 |
| A4 | 原图、左右镜像、上下镜像、180 度 | 4 |
| A5 | 旋转和镜像构成 8 个唯一方向 | 8 |
| B1 | Gamma 0.8/1.0/1.2 | 3 |
| B2 | CLAHE | 1 |
| C0 | A2＋CLAHE | 2 |
| C_without_geometry | CLAHE，等价 B2 | 1 |
| C_without_clahe | A2，等价 A2 | 2 |

两个等价配置必须逐位一致；不一致先查程序和随机数使用，不能当作新方法差异。

## 阈值与选组

1. 每个模型在 34 张原始 val 上取得分数；FAIL 判定为 `score >= threshold`。
2. 枚举唯一分数对应的所有切点（含全 FAIL 与全 PASS），不拆相同分数；阈值用 float64，记录候选表。
3. 只保留 FP≤4 的候选；先 FN 少、再 FP 少、仍并列取较大规范阈值。
4. AE 和监督各自按三种子平均 FN、平均 FP、启用增强项少、视图数少、表中组名顺序选组；完全重复配置优先单项组。
5. 两种方法的代表模型固定为入选组 seed42 第 200 轮，不挑幸运种子。

## 有限改进

以新监督入选组 G_sup 为基础，保留其预处理、增强、标准化器拟合范围与样本权重：

| 配置 | 隐藏层 | L2 | 目的 |
|---|---|---:|---|
| R0 | (64,16) | 0.0001 | 原设置重跑，检验选轮次 |
| R1 | (32,8) | 0.0001 | 单独缩小容量 |
| R2 | (64,16) | 0.01 | 单独加强正则化 |

各 3 种子、全部训练 200 轮；每轮只读 val 分数并按 FP≤4 选阈值，不改变梯度、学习率、顺序或增强采样。每种子最佳检查点：先 FN 少、FP 少，再取较早轮次；保存 best/last 权重、200 轮损失和逐轮 val 分数。R0 第 200 轮必须精确复现同环境 G_sup 对应种子的主实验权重与预测。组间按三种子平均 FN/FP、参数少、L2 小、配置顺序选；代表固定 seed42 已选检查点。

## 默认模型

候选为新 AE 入选组、新监督入选组、新改进入选配置三个代表。在接触 test 前按三种子平均 FN、平均 FP、实际可训练参数量、训练视图数选默认；完全并列按“监督主实验、监督改进、AE”。代表仍固定 seed42。新默认仅表示本轮实验选中，不代表现场合格；旧默认已从当前入口移除。

## 指标与对照

- 图像级 FAIL 为正类：TP/FP/FN/TN、FAIL 精确率/召回率/F1、平衡准确率、覆盖率；分区与来源批次、条件、异常类型、干扰数量、场景组分组报告。
- 恒定 PASS/FAIL 作为无信息对照：val 全 PASS 准确率 20/34=58.82%；全 FAIL 准确率 14/34=41.18%、FAIL F1=28/48=58.33%。
- 11 组×3 种子报告均值±总体标准差（ddof=0，不是置信区间）；单项对 A0、C0 对移除组、两个方法同组对照。
- 稳定性：每图 21 设置（原图 + 2 尺寸×2 填充×5 位置）；固定尺寸比较位置、固定尺寸和位置比较填充；固定原阈值；零翻转不自动等于鲁棒。
- 成本：按 image_id 排序取 val 前 10 PASS、前 10 FAIL，单线程、预加载、每模型预热 2 图、三遍交错，含读图和预处理，报 Median/P95、模型大小与训练耗时；不含摄像头和界面。
