## 5. 75次正式训练协议

### 5.1 共同设置

- 256×256、EXIF方向校正、等比例LANCZOS缩放、居中白色补边、灰度；HOG为9方向、16×16单元、2×2单元块、L2-Hys，共8100维。
- ReLU、Adam、学习率0.001、L2=0.0001、batch size=32、种子42/43/44；200轮，单线程，关闭内部早停。
- 每轮每张原图只取一个随机视图；不通过展开增强图片增加训练预算。保存确定的样本顺序和视图采样规则；同方法重复组相同种子应完全一致。
- AE：`MLPRegressor(hidden_layer_sizes=(64,16,64))`，只用166张PASS；标准化器只拟合这166张训练原图的对应预处理特征，增强特征输入同时作为重建目标，得分为标准化HOG重建均方误差。
- 监督：`MLPClassifier(hidden_layer_sizes=(64,16))`，用249张原图；标准化器只拟合这249张原图；PASS=0、FAIL=1，样本权重固定为PASS=0.75、FAIL=1.5（249/(2×本类数量)）。得分为未校准FAIL输出，不与AE重建误差直接比较数值。
- Gamma仅用于训练。CLAHE组在训练/验证/推理一致应用，clip_limit=0.01；验证和test均不随机增强。
- 主实验每次记录200轮训练损失，固定使用第200轮；不在66次主实验内额外挑轮次。

### 5.2 两种方法各11组×3种子＝66次

| 组 | 设置 |
|---|---|
| A0 | 原图 |
| A1 | 原图＋左右镜像 |
| A2 | 原图＋上下镜像 |
| A3 | 0/90/180/270度旋转 |
| A4 | 原图、左右镜像、上下镜像、180度 |
| A5 | 旋转和镜像构成8个唯一方向 |
| B1 | Gamma 0.8/1.0/1.2 |
| B2 | CLAHE |
| C0 | A2＋CLAHE |
| C_without_geometry | CLAHE，等价B2 |
| C_without_clahe | A2，等价A2 |

必须记录两对等价配置的一致性；失败先查程序和随机数使用，不能当成新方法差异。

### 5.3 选阈值、选组：统一新验证预算

1. 每个模型在34张原始val上取得分数；FAIL判定为score≥threshold。
2. 枚举唯一分数对应的所有判定切点，包含全FAIL和全PASS；对相同分数不拆分。使用float64及有限的规范代表阈值，记录候选表和并列规则。
3. 仅保留FP≤4的候选；先FN最少，再FP最少，仍并列取较大规范阈值。全PASS始终可作为可行候选；若只能得到退化模型如实报告，不伪造成绩。
4. AE和监督各自按三种子平均FN最少、平均FP最少、启用增强项少、视图数少依次选组；完全重复配置优先单项组；最终并列按表中组名顺序取先。
5. 两种方法的代表模型均固定为入选组seed42第200轮，不挑最好种子。

### 5.4 有限改进9次：以新监督入选组为基础

旧B2不会自动成为新基础；必须使用5.3按新数据选出的监督组G_sup，保留它的预处理、增强、标准化器拟合范围与样本权重。

| 配置 | 隐藏层 | L2 | 唯一目的 |
|---|---|---:|---|
| R0 | (64,16) | 0.0001 | 原设置重跑，检验选轮次的效果 |
| R1 | (32,8) | 0.0001 | 单独缩小容量 |
| R2 | (64,16) | 0.01 | 单独加强正则化 |

- 各3种子，全部训练完200轮；每轮只读val分数并按FP≤4选阈值，不影响梯度、学习率、训练顺序和增强采样。
- 每个种子的最佳检查点：先FN少、FP少，再取较早轮次。保存最佳及末轮权重、200轮损失和val逐图分数。
- R0第200轮须精确复现同环境G_sup对应种子的主实验权重和预测；不一致时停止，记录原因，不换候选掩盖差异。
- R0/R1/R2按三种子平均FN、平均FP排序，再优先参数少、L2小；代表模型固定seed42的已选检查点。
- 不追加容量搜索、L2网格、学习率搜索、特征截断、前景分割或离线增强。即使效果不佳，也交付负结果，不自动扩大训练预算。
